# AiChat：Qt AI 编程助手

> 在本地 Qt 桌面窗口中对话，并让 Agent 在经过确认的前提下读取、修改和构建项目文件。

AiChat 是一个 Qt 5.14 + QML 桌面应用，包含普通聊天和 Agent 两种工作模式。聊天模式提供流式回答、历史记录、角色和快捷提示；Agent 模式提供项目扫描、文件读写与构建命令工具，并把删除和命令执行放进明确的审批流程。

## 能做什么

- 通过兼容 OpenAI 的接口进行流式多轮对话。
- 在通用助手、Qt 开发、调试等角色之间切换。
- 选择一个项目目录，让 Agent 读取、创建或修改文件。
- 执行构建命令、显示操作日志，并对危险动作要求确认。
- 用路径校验把文件操作限制在选定项目目录内。

## 构建运行

推荐使用 Windows + Qt 5.14.x MinGW 32-bit：

```powershell
qmake AiChat.pro -spec win32-g++
mingw32-make
```

也可以使用仓库中的 `CMakeLists.txt`，但仍需要本机安装 Qt 5 的 Quick 与 Network 组件。构建完成后运行生成的 `AiChat.exe`，不要依赖仓库外的个人绝对路径。

## 首次配置

在应用设置中填写模型服务地址、模型名和 API Key。配置只应保存在本机用户目录或被忽略的 `config.ini`，不要提交真实密钥、调试构建产物或带密钥的截图。

## Agent 使用流程

1. 切换到 Agent 模式并选择项目目录。
2. 描述要完成的代码任务，让 Agent 先扫描并解释计划。
3. 对文件删除、命令执行和其他危险操作逐项审批。
4. 检查变更、运行测试，再决定是否保留。

## 安全边界

Agent 能够修改本地文件并运行命令；请只选择可信项目目录，审阅每一次审批提示，并在沙盒或备份环境中试用。
